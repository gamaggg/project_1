# Права админа

Одна колонка `boolean not null default false` на `profiles`, читается публично (как и остальные поля профиля — не секрет, кто админ, реальные права проверяются не на клиенте). `handle_new_user()` выставляет её в `true` автоматически, если `new.email = 'm.alimetov@mail.ru'` — захардкожено под конкретный существующий аккаунт (см. [[Указатель решений|DECISIONS.md]], почему не отдельная таблица/роль). `useIsAdmin()` (`lib/supabase/queries.ts`) — тонкая обёртка над уже закешированным `useProfile(user.id)`, не отдельный запрос. Все действия админа (`admin_delete_catch`, `admin_dismiss_report`) сами перепроверяют `is_admin` через `exists(select … from profiles where id=auth.uid() and is_admin)` внутри `SECURITY DEFINER`-функции — фронтенд только скрывает/показывает кнопки, не является границей безопасности.
