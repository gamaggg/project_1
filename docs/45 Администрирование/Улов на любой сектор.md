# Улов на любой сектор

`confirm_catch` не проверяет местоположение вообще (гейт «сектор рядом» — чисто клиентский, в `handlePlus()`) — значит для обхода не нужны ни RPC, ни RLS-правки, только альтернативный UI-путь в камеру. В `TerritoryScreen.tsx`, если `useIsAdmin()`, показывается кнопка «Добавить улов (админ)» рядом с `OwnerRow`; она вызывает `FishZoneApp.startAdminCatch(territoryId)` — тот же хвост, что у `handlePlus()` после успешного `nearestTerritory()` (выставить `catchTerritoryId`, поднять `cameraSessionId`, открыть `screen-camera`), но без единого вызова геолокации. Дальше — тот же камера→форма→`confirm_catch` пайплайн, что у обычного улова; для админа не заведено отдельного пути отправки данных.
