# Перенос улова в другой сектор

Когда GPS ставит улов не в тот сектор (в Москве это частая история), супер-админ на карточке улова нажимает кнопку со стрелкой рядом с корзиной. Открывается `MoveCatchSheet.tsx`:
- схема настоящих сот вокруг текущего сектора (два кольца, из их же `corners`), нужная выбирается нажатием;
- поиск по номеру сектора;
- список ближайших секторов с расстоянием и направлением.

RPC `admin_move_catch(p_catch_id, p_territory_id)` работает только внутри одного города. Итог — как будто улов с самого начала был пойман в новом секторе:
- исходный сектор возвращается тому, чей улов там теперь последний, или освобождается;
- новый переходит рыбаку, если этот улов там самый свежий;
- запись о захвате переезжает вместе с уловом, а если рыбак уже держал новый сектор, она удаляется;
- монеты не пересчитываются, уведомления «сектор забрали» задним числом не рассылаются;
- действие пишется в `admin_actions` (`move_catch`).
