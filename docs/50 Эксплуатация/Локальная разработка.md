# Локальная разработка

- Приложение — `web/` (Next.js 16; перед кодом сверяться с `node_modules/next/dist/docs/`, см. `web/AGENTS.md`).
- Свой Node лежит в `.tools/node/bin`: `export PATH="$PWD/.tools/node/bin:$PATH"`.
- Перед пушем: `npx tsc --noEmit -p .` и `npx eslint <файлы>` в `web/` — Vercel ошибки типов не прощает.
- Dev-сервер для превью: `.claude/launch.json` (порт 3300).
- Переводы: `web/lib/i18n/{ru,en,ka}.ts` — тип словаря требует все ключи во всех трёх языках, хотя приложение пока только на русском.
