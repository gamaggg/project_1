# Лимиты сервисов

Все сервисы RANGE работают на бесплатных тарифах: Supabase Free, Vercel Hobby, Mapbox free tier, Open-Meteo (некоммерческий). Проверка одной командой: **`/limits`** в Claude Code или просто «проверь лимиты». Инструкция и SQL лежат в `.claude/skills/limits/` (`SKILL.md`, `supabase.sql`). Там же таблица лимитов тарифов и правила «светофора».

Команда только читает:
- база — одним SQL-запросом;
- панели Usage Supabase и Vercel — во встроенном браузере (MCP-коннектор Vercel отвечает 403);
- Mapbox и Fishial — оценка по событиям приложения (`app_events`), своих счётчиков у них нет.

> С 27.10.2026 то же самое можно открыть в приложении: профиль → «Лимиты сервисов» (супер-админ или админ с переключателем). Подробности: [[Лимиты в приложении]]. Цифры из панелей Supabase и Vercel лежат в таблице `service_limits_manual`; после каждой проверки `/limits` их нужно обновить, иначе на экране они устареют.

> 27.10.2026: загрузка секторов облегчена ([[Загрузка секторов карты]]), экономия ~0,7–0,8 ГБ трафика Supabase в месяц по замеру; файлы (фото) по-прежнему кончатся около 10 декабря, нужен переезд фото (R2) или платный тариф.

## Почему росли файлы, и что сделали (16.10.2026)
С 05.10 фото улова сохранялось до 1920 px с качеством 0.88 (`CameraScreen.tsx`): снимки стали чёткими, но средний файл вырос со ~100 до ~700 КБ, и файлы прибавляли ~28 МБ в сутки. Карточка улова грузит оригинал, поэтому те же фото давали и основную часть Egress.

16.10: новые фото — до 1600 px, качество 0.82 (~350 КБ, чёткость на телефоне прежняя). Старые пережаты скриптом `web/scripts/recompress-photos.mjs` (один раз, `--apply`): 302 файла из 369 крупных, 222 → 133 МБ (−89 МБ), остальные уже были не больше 1600 px. Адрес файла тот же. Оригиналы лежат в `web/scripts/.cache/photo-backup/` (не в git, 222 МБ): вернуть файл — загрузить копию в тот же путь. Скрипт можно запускать повторно, он трогает только то, что крупнее 1600 px.

Дальше расти будет на ~14 МБ в сутки (было 28): место под файлы кончится не через 3 недели, а через 2 месяца с лишним.
