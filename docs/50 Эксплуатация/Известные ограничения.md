# Известные ограничения

- Realtime не подключён — карта/лента/территории обновляются на фокусе вкладки (react-query `refetchOnWindowFocus`) и сразу после своего собственного улова, но не увидят чужой улов вживую без переключения вкладки/навигации. См. открытый вопрос в [[Указатель решений|DECISIONS.md]].
- Бэкап базы — только ночная зашифрованная копия через GitHub Actions за 30 дней (см. «Резервные копии базы»). Откатиться можно на начало суток, не на любую минуту. Фото из Storage в копию не входят.
- MCP-коннектор Vercel в этой сессии так и не авторизовался (постоянный 403 «Not authorized... re-authenticate to this scope» на любой запрошенный teamId/scope) — весь деплой сделан руками пользователя через веб-интерфейс Vercel, я только диагностировал по скриншотам и логам. См. [[Указатель решений|DECISIONS.md]].
- `web/supabase/` (миграции как файлы) не заведён — схема применена напрямую через Supabase MCP `apply_migration` в разговоре, а не через файлы в репозитории. Если разработка перейдёт на локальный Supabase CLI (`supabase db`), эти миграции стоит выгрузить в файлы для истории/повторяемости.
- Название пойманного вида в ленте активности не склоняется («поймал скорпена», а не «скорпену») — с 36 видами полноценное русское склонение по падежам не стали делать (было и в прототипе для части видов, просто менее заметно при 3 видах). Не блокирует использование, просто не идеально грамматически.
- Геолокация просит разрешение браузера при каждом нажатии «+» (не спрашивает заранее) — если пользователь один раз откажет, браузер обычно предложит снова только вручную через настройки сайта; это стандартное поведение браузера, приложение не пытается обойти отказ повторными попытками.
- Камера (`getUserMedia`) проверена в этой сессии через подменённый `MediaStream` (canvas → `captureStream()`, эмуляция без реального устройства) — весь путь до записи в БД и Storage пройден именно так. На настоящем железе (реальная камера телефона) поведение не проверялось моей стороной — см. открытый вопрос в [[Указатель решений|DECISIONS.md]], стоит попросить пользователя пройти поток на своём телефоне.
