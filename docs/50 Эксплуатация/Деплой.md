# Деплой

Основной домен — **catchrange.com**; какая версия выкачена — `https://catchrange.com/api/version` (хеш коммита). Пуш в `main` → Vercel собирает `web/` автоматически.

```plantuml-svg
@startuml
skinparam shadowing false

node "GitHub\ngamaggg/project_1" {
  artifact "ветка main" as main
  component "Actions:\nDatabase backup" as backup
}
cloud "Vercel" {
  node "проект web\nRoot Directory: web/" as vweb
  artifact "catchrange.com" as domain
}
cloud "Supabase" {
  database "Postgres\nyhgdcdkfkerzuhnzjzrz" as db
}
dev --> main : git push
main --> vweb : автодеплой
vweb --> domain
domain ..> db
dev --> db : миграции через Supabase MCP\n(после прогона и «применяй»)
backup --> db : каждую ночь 00:30 UTC
backup --> main : зашифрованный артефакт\n(gpg, 30 дней)
@enduml
```

## Исходное описание

Продакшен: **https://web-flame-mu-44.vercel.app** (Vercel-проект `web`, команда `gamag`, привязан к `gamaggg/project_1`, ветка `main`, Root Directory `web`). Автодеплой при пуше в `main`.
