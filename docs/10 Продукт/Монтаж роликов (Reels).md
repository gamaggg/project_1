# Монтаж роликов (Reels, TikTok, Shorts)

Часть плана [[Продвижение в соцсетях]]. Видео владельца (рыбалка, вертикальное) превращается в готовый ролик с оболочкой RANGE.

## Что делает генератор
`tools/reels-lab/make_reel.py` + `template_app.py`. Движок: Hyperframes (HTML → MP4, Apache-2.0, `npx hyperframes`), FFmpeg для сжатия.
1. Берёт видео, убирает исходный звук (по умолчанию тишина), при желании подкладывает бесплатную музыку (`--music`).
2. Сверху на всём видео белый логотип RANGE (безопасная зона Reels: под полосой профиля).
3. С выбранной секунды (`--at`) снизу поднимается светлая «карта» (нижние ~40%): 8 секторов в стилях приложения и **настоящая анимация захвата** (серый сектор → падает аватар → заливка цветом волной → белое кольцо → пилюля «Сектор твой · ID» → метка защиты). Над картой «СЕКТОР ЗАХВАЧЕН» и пилюля «рыба · размер · вес». Второй режим `--kind newfish`: «НОВАЯ РЫБА В КОЛЛЕКЦИИ».
4. В конце заставка: «Лови рыбу, захватывай сектора.», `catchrange.com`.
5. Проверка Hyperframes (`check`: контраст, выходы за кадр, анимации) должна пройти, иначе рендер не запускается. Рендер примерно 30–90 секунд на ролик, файл 5–10 МБ.

## Откуда взят вид (не придумано)
Из кода приложения: заливка сектора цветом владельца 0,32 и обводка 1,5 px, свободный серый `#7C7E86` с 0,22 (`LeafletMap.tsx`); цвета `lib/data/territoryColors.ts` («мой» по умолчанию `#2FA84F`); скины — файлы `public/skins/*.svg` (чешуя, полосы, сеть), окрашенные цветом владельца; метка «аватар + id»; момент захвата `.smx-*` в `app/globals.css` (кривые и тайминги те же). Масштаб ×2,77 (390 px приложения → 1080 px).
Условно в ролике: номер сектора (`--sector`, по умолчанию `B0837`) и цвет «моих» (`--color`). Вместо фото-аватаров на секторах иконка рыбки.

## Как это работает для владельца (решено 27.11.2026)
Владелец присылает видео SMM-боту (`@smm_range_bot`, как «видео», до 20 МБ, в подписи можно написать рыбу, вес, место). Бот кладёт файл в корзину `social-videos` и заводит задание в `video_jobs`. Монтаж делается на Mac владельца (Claude по расписанию, инструкция `tools/reels-lab/QUEUE.md`: смотрит видео, режет до 15–20 секунд, накладывает оболочку, пишет описание, **не больше 5 хэштегов**). Готовый ролик (без звука) загружается обратно в корзину, бот присылает его владельцу с описанием и кнопками «✅ Всё ок» и «✏️ Изменить». Правка свободным текстом (ответом на сообщение «Что поменять в ролике #N?») отправляет задание на пересборку. «Всё ок» закрывает задание и удаляет файлы с сервера. **Выкладывает владелец сам** (с трендовым звуком из приложения), автопубликации роликов нет.
- Серверная часть: `web/lib/videoJobs.ts` (приём, отправка, правки), `app/api/social-bot/webhook` (видео, кнопки `vj:`, ответы), `tick` (отправка готовых), `app/api/social-bot/video-slot` (одноразовая ссылка загрузки результата по токену задания). Миграция: `web/supabase-drafts/video-jobs-27-11` (таблица `video_jobs` и корзина `social-videos`).
- Ограничения: Telegram не отдаёт боту файлы больше 20 МБ; монтаж идёт, пока Mac включён и приложение Claude открыто (иначе ролик ждёт в очереди).

## Звук и публикация
- Ролик без звука. Трендовый звук Instagram/TikTok подключается только вручную в приложении (через API нельзя), поэтому Reels и TikTok выкладываются **вручную**: у поста в `social_posts` в `captions` стоит `_manual` = `1`, и бот в назначенное время присылает файл и подпись («Пора выкладывать»), а не публикует сам. Shorts и Facebook можно публиковать автоматом.
- Фоновую музыку с вшиванием не используем без явно проверенной лицензии (бесплатные треки Pixabay Music и т. п. — только с согласия владельца на скачивание). Музыка навыка `/brag` (ende.app) не используется: лицензия не указана.
- Ролики для публикации кладутся на сайт (`web/public/social/reels/`), нужен коммит; в базе пост: `platforms` `["instagram"]`, `kind` `reel`, `media` `[{"type":"video","url":"https://catchrange.com/social/reels/<файл>.mp4"}]`, `captions` `{"_manual":"1"}`.

## Исходники и первые ролики (27.11.2026)
Видео владельца: `1.MOV` пеламида (порт Батуми, 35 см, 380 г), `2.MOV` окунь друга (за городом Батуми), `3.MOV` окунь владельца. Для публикации нужны согласие друга и вес окуней.
