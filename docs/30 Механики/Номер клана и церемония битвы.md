# Номер клана и церемония битвы

- Места: `clans.extra_slots` (0–100, по умолчанию 0) — дополнительные места от супер-админа (`admin_set_clan_extra_slots`, кнопки −5/+5 в блоке модерации клана). Лимит везде = места по уровню (`_clan_capacity(_clan_level(xp))`) + `extra_slots`: `_clan_join_problem`, `get_clan` (отдаёт и `extra_slots`), `list_clans`, `get_share_preview`. Плашки шапки клана открывают `ClanInfoSheet` (уровень и бонусы, лиги, сектора клана).
- Ссылка-приглашение: `shareClan` добавляет `&invite=<код>`, если отправитель — старейшина или выше (`get_clan_invite_code`, код из `clan_invite_codes`). `rememberClanInvite` (`lib/guestShare.ts`) хранит код неделю в `localStorage`, `ClanScreen` получает его как `inviteCode` и вызывает `join_clan` с `p_invite_code`.
- У клана виден номер `ID {clans.id}` (строка списка кланов, чип в шапке). `list_clans` ищет по номеру («15», «#15», «ID 15» — в любом городе) и по названию (в своём городе).
- Церемония итогов битвы (`ClanBattleCeremony`, `lib/clanBattleCeremony.ts`): раз в неделю на город, если клан игрока участвовал; данные — `lastWeek` из `get_clan_race` (тот же запрос, что у плашки на карте), отметка «показано» — `localStorage` с началом текущей недели. Встаёт после окна личных итогов недели и окна достижения. Подиум 2-1-3: столбики вырастают по очереди, гербы падают сверху, свой клан подсвечен, при победе — конфетти; при одном клане — только свой столбик и итог «доплыли / не доплыли».
