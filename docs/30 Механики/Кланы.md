# Кланы

Клан привязан к городу. Создать — игрок с 3+ захваченными секторами, 700 монет. Вступить — в открытый сразу, в остальные по заявке или приглашению.

```plantuml-svg
@startuml
skinparam shadowing false
skinparam roundCorner 10
skinparam defaultFontName Helvetica
skinparam defaultFontSize 13
skinparam ArrowColor #555555
skinparam BorderColor #888888
hide circle
skinparam linetype ortho

entity "clans" as clans {
  * id
  --
  city, name, motto
  crest, background
  join_type, min_sectors
  xp, trophies
}
entity "clan_members" as members {
  * id
  --
  clan_id, user_id
  role
  joined_at, left_at, city
}
entity "clan_weeks" as weeks {
  * clan_id
  * week_start
  --
  chest_points, chest_tier
  race_meters, race_finish
  race_place, race_coins, race_trophies
}
entity "clan_messages" as messages {
  * id
  --
  clan_id, user_id, body
}
entity "clan_join_requests" as requests {
  clan_id, user_id
}
entity "clan_invites" as invites {
  clan_id, user_id, invited_by
}
entity "clan_events" as events {
  * id
  --
  clan_id, kind
  actor_id, target_id
}
entity "profiles" as profiles {
  * id
}

clans ||--o{ members
profiles ||--o{ members
clans ||--o{ weeks
clans ||--o{ messages
clans ||--o{ requests
clans ||--o{ invites
clans ||--o{ events
@enduml
```

- Данные: `clans`, `clan_members` (с историей — `left_at`/`left_reason`), `clan_join_requests`, `clan_invites`, `clan_events` (журнал), `clan_weeks` (итоги недели: сундук, битва кланов, `race_void`).
- Экраны: `ClanListScreen` (поиск, приглашения, создание), `ClanScreen` (шапка `ClanHero`, вкладки «Участники / Сундук / Битва кланов», блок модерации для супер-админа), `ClanEditorScreen` (создание и настройки, 4 шага с живым превью), `ClanRaceScreen` (битва кланов целиком). Вход — карточка клана в профиле, пилюля в чужом профиле, строка клана на экране сектора, вкладка «Кланы» в рейтинге, ссылка `?clan=ID`.
- Герб — `ClanCrest` (форма + символ + два цвета, `lib/data/clanCrests.ts`), фон — `lib/data/clanBackgrounds.ts`, уровни/лиги/роли — `lib/data/clanLevels.ts`.
- Карта, верх — одна панель `.map-hud` на всю ширину (MapScreen): логотип и переключатель «Игроки | Кланы» в первой строке, под ними легенда в одну строку (мои / чужие / свободные, либо гербы топ-3 кланов с числом секторов и «Без клана»), а у игрока в клане — оранжевый низ панели «Битва кланов» (`MapRacePill`: место или % пути, время до итогов, полоска прогресса). Слой «Кланы»: сектора в цвет герба владельца, одиночки серые, на метках гербы; выбор слоя запоминается на устройстве.
- **Что видно о чужом клане** (решение владельца 09.11.2026): уровень клана, где стоит штаб, осада и руины, база с шестью постройками и их **уровнями** (все шесть, в том числе крепость и маяк). Не показывается и сервером не отдаётся: баланс и журнал общака, ставка отчисления, план бафа «Выход», кто и сколько вносил. На экране чужого клана (вкладка «Участники») карточка базы `ForeignBase` (`components/clan2/live/ForeignBase.tsx`) на данных `get_clan_bases`; показывается, только если штаб чужого клана есть в списке карты текущего города и пришёл с сервера (условные постройки предпросмотра за настоящие не выдаются); для клана другого города карточки базы нет (на его сектора нет карты этого города).
- **Вкладка «Кланы» на экране «Сектора»** (`ClanRating`): рейтинг кланов своего города (подиум и список до 30, кнопка «Все кланы города»), а под ним блоки по остальным городам, где есть кланы (до 10 кланов на город, строка как у своего списка, заголовок — название города). Данные те же `list_clans` по каждому городу (миграции не нужны), ключи запросов общие с `useClanList`. Клан другого города можно открыть и посмотреть, вступить в него нельзя (экран клана пишет, что он в другом городе).
- **Роли и кто кого двигает** (`set_clan_member_role`, меню участника в `ClanScreen`): глава назначает кого угодно и один передаёт руководство (прежний глава становится соруководителем). С 09.11.2026 соруководитель (в FAQ «заместитель») может поднять участника и старейшину до старейшины и соруководителя, а старейшину опустить до участника; других соруководителей и главу он не трогает, себя тоже. Раньше соруководитель двигал только участник ↔ старейшина. Черновик: `supabase-drafts/clan-coleader-promote-09-11/`.
- У игрока может быть клан в каждом городе; всё, что «мой клан», — это клан текущего города профиля. Действия в клане передают `clanId` явно.
- Гербы у имён: в недельном рейтинге (`useClanBadges` → `get_clan_badges`, запрос только когда открыт рейтинг) и на карточках секторов (`ownerClanCrest` из `territories_with_stats`).
- Хуки — в `lib/supabase/queries.ts` (`useClan`, `useClanList`, `useClanChest`, `useClanRace`, `useClanBadges`, `useAdminModerateClan` и т.д.); после изменения членства — `invalidateClanMembership()`.
- Общий сектор: улов соклановца на секторе клана (клан города сектора) добавляет его в `territory_shares` — до 4 держателей вместе с хозяином, пятый просто поддерживает. `territories_with_stats.co_holders` → `Territory.coHolders` (у каждого `isMe`). Хозяин (`owner_id`) остаётся хозяином для щита и битвы кланов. Счётчик секторов (`profiles_with_stats.territories_count`: «Все игроки», админ-список) считает владение плюс доли, как карта и «Мои» (с 18.10; раньше считал только владение). В рейтинге недели (и его итогах) и в достижениях доля считается целым сектором: `_weekly_sector_counts` на сервере, `heldTerritories()` в `lib/data/achievements.ts` на клиенте. Смена хозяина (чужой захват, модерация, перенос улова) обнуляет доли и шлёт бывшим совладельцам «сектор забрали» (триггер `territories_owner_changed`); выход из клана снимает доли ушедшего и доли на его секторах (`clan_members_left_shares`).
- «Захватил сектор» на общем секторе — держатель (хозяин или совладелец) с самым свежим уловом на этом секторе: `territories_with_stats.capturer_id` → `Territory.capturerId`, выбор — `lib/data/sectorHolders.ts`. Остальные держатели — в «Совладельцах». Хозяин в базе (`owner_id`) от этого не меняется.
- Рисунок общего сектора — `lib/map/sectorParts.ts` (`splitSector`): сота режется на 2 (верх/низ), 3 («Y») или 4 («+») равные части, часть 0 — хозяину. На карте части — отдельные неинтерактивные полигоны под контуром соты, линии разреза белые, аватарки в центрах частей, номер в центре соты; на слое «Кланы» — один герб. На экране сектора — то же на мини-карте (`TerritoryThumbnailMap`) и блок «Совладельцы»; своя часть — своим цветом, значок «Моя доля».

- Возврат в клан (`_clan_join_problem`, им же проверяют `join_clan`, `invite_to_clan`, `respond_clan_join_request`): после любого выхода или исключения игрок 24 часа не может вступить ни в один клан своего города (`cooldown`); исключённый в тот же клан не вернётся 72 часа после исключения (`kicked_recently`, и приглашение, и заявка). Вышедший сам вернуться может через сутки. Текст отказа называет срок (с 18.10); в FAQ — вопрос «Я исключил игрока… когда можно позвать обратно?».
