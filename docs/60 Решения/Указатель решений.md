# Указатель решений

Здесь фиксируется **почему** сделано так, а не иначе — чтобы не переоткрывать одни и те же вопросы. Каждое решение (ADR) — отдельная заметка, по порядку принятия. Внутри у каждой — исходные пункты «**Решение: …**» с причинами; отменённые помечены «Заменено».
