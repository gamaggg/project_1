# Челленджи недели считаются по своему городу

**Решение: у строки челленджа есть город (`user_challenges.city`), прогресс считается по нему, а не по городу того, кто вызвал проверку**
Наборы челленджей уже были раздельными по городам: неделя начинается в полночь города (Батуми — 20:00 UTC, Москва — 21:00 UTC), и после смены города создаётся второй набор. Но `sync_my_challenges` закрывал **все** незакрытые строки игрока по городу из своего вызова, поэтому московские уловы закрыли батумские «Трофей» и «Ихтиолог» (30.09). Теперь в цикле закрытия каждая строка считается по своему городу и его часовому поясу (`_city_tz`). Колонку заполнили по часу начала недели (других значений в таблице не было), новые строки из `sync_my_challenges` и `buy_extra_challenge` получают `p_city`.

**Решение: челлендж закрывается атомарно**
`update … where id = … and settled = false`, и монеты начисляются только если строка действительно обновилась (`found`). Раньше две одновременные проверки обе видели челлендж открытым и платили дважды — один такой случай, «Дальнобойщик» 25.09.

Аккаунт супер-админа исправлен вручную: оба челленджа снова открыты, списано 135 монет (30 + 55 + двойные 50), запись в `admin_actions` (`fix_challenges`). Прошлые недели других игроков не пересчитывались: часть уловов с тех пор удалена, и пересчёт задним числом был бы ненадёжен.
