# Фоны клана: светлые пресеты и синхронная «Аврора»

**Решение: светлые фоны клана используют тот же `textRgb`, что и профиль**
Шапка клана выставляет `--hero-text-rgb` (по умолчанию белый) и класс `clan-hero-light`. Все цвета текста, чипов и полосы опыта в шапке берутся из этой переменной, поэтому светлые «Авроры» читаются без отдельной вёрстки.

**Решение: фаза «Авроры» привязана к часам**
`AuroraBackground` ставит отрицательный `animation-delay` = текущее время по модулю длины цикла (24 с). Плитки, смонтированные в разные моменты, идут в одной фазе: раньше выбранная плитка заметно обгоняла остальные. Для превью (`variant="swatch"`) фон 150% вместо 300% со сдвигом 300% — бесшовный цикл по той же формуле, что и для шапки.
