# Резервные копии базы — ночью через GitHub Actions, зашифрованные

**Решение: своя ночная копия вместо тарифа Pro**
Бесплатный тариф Supabase бэкапов не делает. Самый вероятный способ потерять данные — собственная ошибка: миграции идут прямо в боевую базу, за первый месяц их было 184. Pro ($25 в месяц) даёт ежедневные бэкапы за 7 дней, но денег на него пока нет. Поэтому GitHub Actions каждую ночь снимает дамп по инструкции Supabase (роли, схема, данные) и хранит 30 дней. Для публичного репозитория это бесплатно. Как настроить и восстановить — [[00 Главная|DOCS.md]], «Резервные копии базы».

**Решение: копия шифруется паролем до сохранения**
Репозиторий публичный: артефакты и логи может скачать любой пользователь GitHub, а в дампе почты и хэши паролей игроков. Поэтому архив шифруется (gpg, AES-256) паролем из секрета `BACKUP_PASSPHRASE`, а в логе только размеры и число строк. Перед сохранением задача проверяет, что архив открывается тем же паролем. Асимметричное шифрование (ключ только у владельца) было бы строже, но требует отдельного ключа и программы для расшифровки. Пароль из секрета проще, и его достаточно, пока доступ к настройкам репозитория только у владельца.
