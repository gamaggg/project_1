# Подсказки и тур «Что нового»

Экран затемняется вокруг одного элемента (`data-tour="…"`), рядом — карточка с текстом, «Далее» / «Пропустить» (`SpotlightTours.tsx`). Какие туры есть и для кого — `lib/data/tours.ts`; тексты — `tour.<ключ>.title / text` в словарях. Показанные туры хранятся на устройстве и на аккаунте (`user_ui_state`, ключ `tours:<версия>:<аудитория>`), поэтому тур, пройденный в телефоне, не повторяется в Telegram на компьютере. Два тура не идут одновременно (`lib/tourLock.ts`).

Аудитории: `newcomer` («Подсказка» — новые игроки, экран за экраном) и `whatsNew` («Новое» — те, кто играл до обновления, аккаунт старше суток).

## Тур обновления 16.10 (`UPDATE_16_10_TOURS`, только `whatsNew`, `always` — виден и тем, кто раньше нажал «Пропустить»)
| Экран | Что подсвечено | О чём |
|---|---|---|
| Карта | легенда («Мои · Чужие · Свободные») | сектора в цвете владельцев |
| Профиль | плитка «видов рыб» → карточка «Челленджи» → выбор языка | статистика видов · обновлённые челленджи · английский и грузинский (шаг про язык — только пока выбор языка включён) |
| Челленджи | путь недели → первое задание | узлы с галочками и раскрывающиеся карточки, «в зачёте», частичная награда |
| Клан → «Сундук» | ряд сундуков → «Твой вклад» | сундуки нажимаются, личный вклад и награда |
| Карточка своего улова | фото → кнопка «Размер, вес» | фото на весь экран с приближением · дополнить улов позже |
| Территории → «Рейтинг» | переключатель «Неделя / Все игроки» | список всех игроков с поиском и фильтром |

### Обновление 19.10 — битва кланов по записи (`u1910-…`)
Только для игроков в клане (элементов нет у остальных). `always`, по одному разу на аккаунт.

| Экран | Шаги | О чём |
|---|---|---|
| Карта | плашка «Битва кланов» (`race-pill`) | клан участвует, только если глава или соруководитель открыл битву; «не начата», нажатие ведёт в битву |
| Экран «Битва кланов» (`u1910-race`) или вкладка «Битва кланов» в клане (`u1910-clan`) | карточка состава и старта (`war-card`) → блок «Как проходит битва» (`race-how`) | состав от 3 игроков, метры только у состава, состав после старта не меняется · четыре интерактивных шага |

Экран битвы и вкладка клана показывают одни и те же две карточки, поэтому каждый из двух туров не показывается, если уже виден другой (`unlessSeen`). Затемнение, подсветка и кнопка «Понятно» — как у остальных туров.

Шаги, чьего элемента у игрока нет, пропускаются; тур стартует на своём экране, когда ключевой элемент появился. Версия туров `2026-10` не менялась: у каждого тура новый `id` (`u1610-…`), поэтому старые отметки их не гасят.

## Как добавить тур к новой функции
Пометить элемент `data-tour`, добавить ключ в `TourKey`, тур в нужную аудиторию, тексты ru/en/ka (`tour.<ключ>`), строку — в эту таблицу.
