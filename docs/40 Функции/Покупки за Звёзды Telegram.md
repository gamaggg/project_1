## Покупка с сайта и из установленного приложения (с 26.11.2026)
Звёздами платят только внутри Telegram. Вне его кнопка с ценой открывает окно «Оплата Звёздами — в Telegram» (`BuyInTelegram.tsx`) с кнопкой «Открыть в Telegram».
- Ссылку выдаёт `app/api/telegram/buy-link`: одноразовый ключ из `telegram_link_tokens` (тот же, что у «Подключить Telegram», 15 минут, `create_telegram_link_token` под сессией самого игрока) и товар. Без Main Mini App ссылка ведёт в бота: `t.me/catchrangebot?start=b_<ключ без дефисов>_<товар>` (до 64 символов), бот отвечает кнопкой «⭐ Открыть и купить» в Mini App на `/?tglink=<ключ>&buy=<товар>`. Если задан `NEXT_PUBLIC_TG_APP_LINK`, ссылка сразу открывает Mini App через `startapp`.
- В Telegram `TelegramClaim.tsx` (подключён в `AuthProvider`) отправляет ключ и подписанные данные Telegram в `app/api/auth/telegram/claim`: этот Telegram привязывается к аккаунту с сайта, приложение входит в него и перезагружается с `?buy=`. `FishZoneApp` открывает магазин на вкладке товара с его окном (монеты и ключи — экран «Пополнить»).
- Если на этом Telegram уже есть другой аккаунт: пустой (ни уловов, ни клана, создан самим Mini App) отпускает Telegram сразу; аккаунт с игрой — окно выбора: «Привязать Telegram к «основной»» (с подтверждением: если у второго нет почты, войти в него больше нельзя, данные не удаляются, доступ возвращает поддержка) или «Остаться в «втором»» (ничего не меняется, ключ сгорает, покупка открывается во втором аккаунте). Объединить игру двух аккаунтов нельзя.
- Если у аккаунта с сайта был привязан другой Telegram, привязка переходит на тот, где человек открыл ссылку.
- Ключ одноразовый, 15 минут; устаревший — окно «Ссылка устарела». Новая ссылка (или «Подключить Telegram») гасит прежние ключи.

Цены выбрал Claude по просьбе владельца («сам реши»): 1 ⭐ ≈ 2 цента для покупателя (≈ 1,65 ₽, ≈ 0,05 ₾ на 25.11.2026), разработчику приходит меньше (доля Telegram и магазинов приложений; курс вывода сверить перед запуском). Товары и цены — таблица `stars_products` (поле `active` снимает товар с продажи).

Ключ = бесплатное открытие секретного бокса (`secret_box_free`, то же, что 3 ключа в слотах). Скины за Звёзды — `shop_items` с `purchasable = false` и ценой 3 000 (цена только для вида и защиты: вещь с ценой 0 `equip_shop_item` надевает без покупки); за монеты не продаются, в бокс не попадают, на вкладке скинов за монеты видны, только если уже куплены.

## Как идёт оплата
1. Магазин → вкладка «Звёзды» (монеты и ключи, `components/app-shell/StarsShop.tsx`) или кнопка «Пополнить» на карточке баланса; скины за Звёзды — на обычной вкладке «Скины» с ценой в Звёздах и тремя звёздочками ✦✦✦. Вне Telegram кнопки только подсказывают, где купить.
2. `POST /api/stars/invoice` → `stars_order_create` под игроком (товар активен, скина ещё нет, покупки открыты) → `createInvoiceLink` (валюта `XTR`, без провайдера, payload = id заказа) — `lib/telegram/stars.ts`.
3. Приложение открывает счёт `WebApp.openInvoice`.
4. Telegram спрашивает бота `pre_checkout_query` → `stars_precheck` (заказ ждёт оплаты, сумма та же, скина нет) → `answerPreCheckoutQuery` (за 10 с).
5. `message.successful_payment` → `stars_fulfill`: выдать один раз на заказ (повтор того же апдейта ничего не добавляет), сообщение в чат «Спасибо за покупку». Ошибка базы → вебхук отвечает 500, Telegram пришлёт апдейт снова.

Таблицы `stars_products`, `stars_orders` закрыты для приложения; `stars_precheck` / `stars_fulfill` — только сервер (service_role). В истории монет — «Покупка за Звёзды: N монет» (`stars_purchase`).

## Скины
Узор скина — настоящий шейдер своего фона (владелец: «почему не похоже на фоны, бери именно узор, что он даёт»). `lib/map/glSkinRenderer.ts`: на каждое семейство один скрытый холст WebGL, который рисует сцену фона (те же шейдеры, что у фона профиля) в «светлом» режиме сцен (там свет превращается в чернила) и оставляет от неё только узор: прозрачность = плотность рисунка, без тёмной подложки. Каждый сектор копирует свой кусок этого холста (по своему seed, чтобы соседи не совпадали), заливка сектора остаётся видна. Без WebGL рисуются плоские запасные версии из `lib/map/glSkins.ts`. Холст отдаётся обратно через 4 секунды простоя (на телефоне мало графических контекстов). Продаются отдельно, в комплект не входят.

## Куда приходят Звёзды и уведомление владельцу
- Звёзды покупателей копятся на балансе бота @catchrangebot (счёт самого бота в Telegram). Смотреть и выводить: в Telegram у бота есть баланс Звёзд (через @BotFather / профиль бота; вывод в TON через Fragment по правилам Telegram: минимальная сумма и срок удержания, их проверять в самом Telegram).
- Каждая оплата сразу присылает владельцу (всем суперадминам с Telegram) сообщение в бота: что куплено, сумма в ⭐, кто (имя и ID игрока), когда (время по Тбилиси), «Всего заработано N ⭐ за M покупок» и «Сегодня K ⭐». Код: `notifyOwnerOfSale` в `lib/telegram/stars.ts`, вызывается после выдачи покупки; ошибка отправки не ломает выдачу. «Всего» — сумма оплаченных заказов (`stars_orders`, status paid), то есть сколько Звёзд заплатили покупатели; сколько дойдёт на баланс бота после доли Telegram, видно в самом Telegram.

## Не сделано / ограничения
- Возврат Звёзд (`refundStarPayment`) — пока только вручную владельцем через бота; кнопки в админке нет.
- Вне Telegram (сайт, приложение на главном экране) купить нельзя.
- Настоящая оплата проверяется только в Telegram на телефоне.
