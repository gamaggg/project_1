# Покупки за Звёзды Telegram

С 25.11.2026 (черновик `web/supabase-drafts/economy-24-11/11_telegram_stars.sql`, выпуск вместе с боксом — `05_release.sql`, флаг `feature_release('stars')`). До выпуска покупки видит только суперадмин.

## Что продаётся
| Товар | Звёзды |
|---|---|
| 500 монет | 50 |
| 1 500 монет | 125 |
| 5 000 монет | 350 |
| 1 ключ | 40 |
| 3 ключа | 100 |
| 5 ключей | 150 (черновик `14_keys_5.sql`) |
| Скины секторов (пять по узору фонов: сияние, звёздное небо, частицы, лучи, матрица; `skin_gl_*`) | по 150 (черновик `15_gl_skins.sql`; прежние «Медузы», «Лава», «Созвездия» убраны) |
| Живой фон профиля (семь) | по 150 |
| Рамка и стиль имени к фону (семь + семь) | по 100 |
| Комплект фон + рамка + имя (семь) | по 300 |

Фоны, рамки, имена и комплекты: [[Живые фоны, рамки и комплекты]].

Цены выбрал Claude по просьбе владельца («сам реши»): 1 ⭐ ≈ 2 цента для покупателя (≈ 1,65 ₽, ≈ 0,05 ₾ на 25.11.2026), разработчику приходит меньше (доля Telegram и магазинов приложений; курс вывода сверить перед запуском). Товары и цены — таблица `stars_products` (поле `active` снимает товар с продажи).

Ключ = бесплатное открытие секретного бокса (`secret_box_free`, то же, что 3 ключа в слотах). Скины за Звёзды — `shop_items` с `purchasable = false` и ценой 3 000 (цена только для вида и защиты: вещь с ценой 0 `equip_shop_item` надевает без покупки); за монеты не продаются, в бокс не попадают, на вкладке скинов за монеты видны, только если уже куплены.

## Как идёт оплата
1. Магазин → вкладка «Звёзды» (монеты и ключи, `components/app-shell/StarsShop.tsx`) или кнопка «Пополнить» на карточке баланса; скины за Звёзды — на обычной вкладке «Скины» с ценой в Звёздах и тремя звёздочками ✦✦✦. Вне Telegram кнопки только подсказывают, где купить.
2. `POST /api/stars/invoice` → `stars_order_create` под игроком (товар активен, скина ещё нет, покупки открыты) → `createInvoiceLink` (валюта `XTR`, без провайдера, payload = id заказа) — `lib/telegram/stars.ts`.
3. Приложение открывает счёт `WebApp.openInvoice`.
4. Telegram спрашивает бота `pre_checkout_query` → `stars_precheck` (заказ ждёт оплаты, сумма та же, скина нет) → `answerPreCheckoutQuery` (за 10 с).
5. `message.successful_payment` → `stars_fulfill`: выдать один раз на заказ (повтор того же апдейта ничего не добавляет), сообщение в чат «Спасибо за покупку». Ошибка базы → вебхук отвечает 500, Telegram пришлёт апдейт снова.

Таблицы `stars_products`, `stars_orders` закрыты для приложения; `stars_precheck` / `stars_fulfill` — только сервер (service_role). В истории монет — «Покупка за Звёзды: N монет» (`stars_purchase`).

## Скины
Рисуются вживую в `lib/map/glSkins.ts` узором своего фона поверх обычной заливки сектора, без собственного фона (владелец: «зачем фон на скине сектора, бери только узор»). Контрастно, как остальные скины: сияние в цветах семейства, остальные тёмным оттенком цвета самого сектора с белыми бликами (звёзды-«искры», точки, лучи с яркой головой, падающие знаки), линии потолще. Продаются отдельно, в комплект не входят.

## Не сделано / ограничения
- Возврат Звёзд (`refundStarPayment`) — пока только вручную владельцем через бота; кнопки в админке нет.
- Вне Telegram (сайт, приложение на главном экране) купить нельзя.
- Настоящая оплата проверяется только в Telegram на телефоне.
