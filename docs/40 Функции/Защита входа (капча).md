# Защита входа и регистрации (капча)

Перед входом по паролю, регистрацией, «Забыл пароль» и повторной отправкой кода приложение просит у Cloudflare Turnstile одноразовый токен и передаёт его в Supabase Auth (`options.captchaToken`). Supabase проверяет токен своим секретным ключом. Проверка невидимая: человека о чём-то просят (поставить галочку), только если Turnstile сам не уверен.

## Что в коде (20.10.2026)

- `web/lib/captcha.ts`: `getCaptchaToken()` (свежий токен на каждый вызов, один виджет на всю сессию), `isCaptchaError()`, `CAPTCHA_ENABLED`. Скрипт Cloudflare подгружается только при первой попытке входа или регистрации.
- Вызывается в `SignInStep` (вход), `AccountStep` (регистрация и повторная отправка кода), `ForgotPasswordFlow` («Забыл пароль» и повторная отправка кода). Ошибка проверки показывается текстом «Не удалось пройти проверку «Я не робот»…» (`onb.captchaFailed` на ru/en/ka).
- Без `NEXT_PUBLIC_TURNSTILE_SITE_KEY` ничего не грузится и токен не посылается: приложение работает как раньше, пока капча в Supabase выключена.
- **Не затронуто:** вход через Telegram (сервер создаёт сессию через admin API, `app/api/auth/telegram/route.ts`), проверка кода из письма (`verifyOtp`), привязка почты (`updateUser`). Капча к ним не применяется.

## Как включить (порядок важен)

1. Cloudflare → Turnstile → Add widget: домен `catchrange.com` (для проверки на своём компьютере ещё `localhost`), режим Managed. Получить **Site key** и **Secret key**.
2. Vercel → проект `web` → Settings → Environment Variables: `NEXT_PUBLIC_TURNSTILE_SITE_KEY` = Site key (Production и Preview), затем Redeploy.
3. Только после того, как сборка с ключом вышла: Supabase → Authentication → Attack Protection (в новых версиях панели — Authentication → Settings) → включить CAPTCHA, провайдер Cloudflare Turnstile, вставить Secret key.

Если включить капчу в Supabase раньше, чем выйдет сборка с ключом, вход и регистрация перестанут работать (Supabase будет отказывать запросам без токена). Откат: выключить CAPTCHA в Supabase, это мгновенно.

## Проверка

Cloudflare даёт тестовые ключи: Site key `1x00000000000000000000BB` (невидимая, всегда пропускает), `3x00000000000000000000FF` (всегда просит галочку). Проверено на локальной странице: виджет загружается, два вызова подряд дают два токена.
