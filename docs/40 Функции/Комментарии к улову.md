# Комментарии к улову

Шторка `CommentsSheet.tsx` открывается с карточки улова (`CatchPhotoScreen` — кнопка со счётчиком и превью двух последних комментариев) и по ссылке `?catch=ID&comment=CID` (подсветка комментария). Данные — `get_catch_comments` (одним запросом, с именем, аватаром, стилем имени и гербом клана автора); запись — только через RPC `post_comment` / `delete_comment` / `report_comment`. Лимит 300 символов (`COMMENT_MAX_LENGTH` в `lib/moderation.ts`), модерация — `moderate_text` в базе, коды причин переводятся в текст `moderationMessage()`. Уведомления `catch_comment` / `comment_reply` — в «Активности» и в Telegram. Жалобы — вкладка «Комментарии» в `AdminReportsScreen`.
