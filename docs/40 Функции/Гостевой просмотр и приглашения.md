# Гостевой просмотр и приглашения

- Ссылки «Поделиться» (сектор, профиль, улов, клан, достижение) несут `&ref=<public_id>` поделившегося (`refParam` в `lib/guestShare.ts`).
- Без входа такая ссылка открывает `GuestShareScreen` вместо приветствия: экран целиком, только для чтения (`get_share_preview` — функция доступна без входа, отдаёт только то, что видит любой игрок, у сектора — без координат), снизу закреплён блок «Создать аккаунт / Войти» с текстом под ситуацию. Любое действие (профиль, улов, лайк, точка и маршрут) открывает окно «доступно игрокам»; на карту и другие экраны уйти нельзя. «Назад» из регистрации/входа возвращает на этот экран (`OnboardingFlow` `initialStep`/`onBackToShare`), после входа ссылка открывает экран по-настоящему.
- Приглашения: `ref` запоминается в `localStorage` (неделю) и после онбординга уходит в `claim_referral` — новичку 100 монет (только аккаунт младше 3 дней без уловов, один раз), пригласившему — уведомление `referral_joined`. Первый улов новичка платит пригласившему 100 монет и шлёт `referral_reward` (триггер `catches_referral_reward`, не больше 50 наград на человека). Оба уведомления — в «Активности» и Telegram.
- В разработке `&guest=1` показывает гостевой экран и во вошедшей сессии.
