# Виды рыб (статистика коллекции)

Открывается из профиля (своего и чужого) по плитке «видов рыб». Данные — список уловов, который экран профиля уже держит (`speciesBreakdown()` в `lib/format.ts`: по виду — число, первый и последний улов, рекорд длины и веса, id последнего и рекордного улова) плюс справочник видов `useSpecies()` (размер всей коллекции и недостающие виды). Новых запросов нет.

- **Кольцо «собрано N из M»**: M — виды городов, где игрок ловил (Батуми: морские + пресноводные, Москва: хищные + мирные; ловил в обоих — оба набора).
- **Полоса по категориям** и такие же чипы — нажатие фильтрует список.
- **Три плитки**: число уловов, самая крупная рыба (нажатие открывает улов), любимый вид (нажатие открывает его последний улов).
- **Сортировка**: чаще / крупнее / свежие.
- **Строка вида**: полоска доли от самого частого; нажатие раскрывает рекорды длины и веса, первый и последний улов, долю от всех уловов и кнопки «Последний улов» / «Рекордный улов».
- **«Ещё не пойманы · N»**: сворачиваемый список названий с замочками; когда собраны все — «Коллекция собрана целиком!».
