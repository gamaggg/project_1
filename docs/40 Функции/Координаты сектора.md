# Координаты сектора

- На экране сектора строка с координатами центра («41.54334, 41.55939»): «Скопировать» и «Маршрут» — Google / Яндекс / Apple Карты (`lib/openExternal.ts`, в Telegram через `WebApp.openLink`). Гостю вместо неё — «Точка на карте и маршрут — после регистрации».
