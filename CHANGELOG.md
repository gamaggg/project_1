# FishZone — журнал изменений

Формат: дата (сессии) не фиксируется автоматически — при переносе в реальный проект дописывайте дату коммита. Каждая запись = один запрос пользователя и что было сделано.

---

## Инициализация проекта
- Собран MVP мобильного приложения для береговой рыбалки в Батуми по исходному ТЗ (Strava-style, не игра).
- Единый файл `fishzone-app.html` (HTML/CSS/JS, без сборки), рендерится как мобильный экран 390×844.
- Экраны: Карта, Территории, Камера (фиксация улова), Подтверждение улова, Активность, Профиль.
- Реальная карта на Leaflet + OpenStreetMap тайлы.

## UI-полировка
- Единый шрифт (Manrope) на всё приложение, включая GPS-чип на камере (раньше был отдельный monospace).
- Плавные переходы между экранами (кроссфейд + подъём) вместо резкого display:none/flex.
- Углублены тени, добавлены градиенты на кнопках, тактильный отклик (scale на нажатии) почти на всех интерактивных элементах.
- Добавлен минимальный брендинг-лого на экране карты.

## Баг: тайлы карты с водяным знаком «API KEY REQUIRED»
- Причина: CARTO закрыл бесплатный доступ к своим базовым тайлам.
- Исправление: переход на стандартные тайлы OpenStreetMap (без ключа) + CSS-фильтр (grayscale/contrast) для приглушённого «премиального» вида вместо туристической пестроты OSM по умолчанию.

## Баг: территории на карте не совпадали с береговой линией
- Несколько итераций проблемы:
  1. Первая версия — повёрнутые квадраты по 2 опорным точкам берега → диагональ резала город.
  2. Убрали поворот (axis-aligned квадраты через divIcon) — устранило часть багов, но перестало «облегать» изгиб берега.
  3. Вернули поворот через две смещённые кривые (земля/море) + нарезку на полосы — сложная геометрия, часть багов с самопересечением полигонов.
  4. По просьбе пользователя — сектора стали шестиугольниками (сотами), шаг 300 м, каждый сектор ориентируется по касательной ЛОКАЛЬНО (не по одной глобальной линии).
  5. Обнаружено: направление менялось только в 6 точках стыка исходных опорных точек → между ними ряд был прямым. Добавили сглаживание сплайном (Catmull-Rom) — не прижилось при дальнейшей правке.
  6. **Финальное решение**: убрали сплайн и любые «глобальные линии» вообще. Ввели `SECTOR_POINTS` — явный список `{ id, lat, lng }`, по одной точке на сектор. Ориентация и размер каждого шестиугольника считаются от соседних точек в списке (направление на предыдущую/следующую точку). Это даёт полный ручной контроль без скрытой математики.
- Отдельная проблема: часть опорных координат указывала на объекты в глубине города (например, «Центральный парк Батуми»), а не на набережную → линия срезала через кварталы. Пересчитано через проверенные прибрежные ориентиры (Iveria Beach, Alphabet Tower, Radisson Blu, парк Batumi Boulevard, Batumi Beach, озеро Ардагани, южный кластер New Boulevard), найденные через Google Places.

## Баг: карточка сектора на карте перекрывалась нижним меню
- Карусель карточек (`map-sheet-container`) была позиционирована `bottom:12px`, залезала под `bottomnav`.
- Исправление: `bottom:94px` (высота меню + отступ).
- Побочный баг: при подъёме карточек случайно занизили `z-index` карусели ниже, чем внутренние z-index панелей Leaflet (тайлы/маркеры) → карточки визуально «исчезли» под картой. Возвращён `z-index:700`.

## Баг: кнопка камеры перекрывалась нижним меню
- При открытии полноэкранной камеры `bottomnav` теперь скрывается (`display:none`), возвращается при выходе из экрана камеры.

## Функция: свайп карточки сектора → карта летит к нему
- Карусель карточек через нативный горизонтальный скролл (`scroll-snap`).
- При свайпе (через `scroll`-listener с debounce) карта делает `flyTo` на выбранный сектор.
- Баг: `zoomend` (срабатывающий из-за `flyTo`) был подписан на полную перерисовку карусели → карусель сбрасывалась на первую карточку → карта возвращалась обратно к «моей территории». Исправление: перерисовка квадратов на зуме отделена от перерисовки карусели; карусель теперь обновляется только там, где это действительно нужно (при первой загрузке и после подтверждения улова).

## UI-правки по месту
- Убраны точки-пагинация под карточками карты (по просьбе).
- Убрана тень у карточек карты (по просьбе).
- Кнопка «+» в нижнем меню: без текста, крупнее, плюс всегда белый (был перебит общим CSS-правилом `.navitem svg{stroke:...}` — добавлено точечное `!important`). Кнопка выровнена в один уровень с остальными пунктами меню (убрана приподнятая «плавающая» версия).
- Добавлен раздел «Достижения» на экране профиля (реальные вехи: первый улов, три территории, коллекционер видов, ранний рыбак, личный рекорд 40+, десять уловов) — не игровые очки, а прогресс по реальной статистике.
- Убраны текстовые названия и типы секторов («Пирс у Дельфинария», «Волнорез» и т.п.) — сектора идентифицируются только номером (`id`). Обновлены все экраны, где раньше показывалось название/тип: карточка территории, карусель на карте, подтверждение улова, успех, лента активности, профиль.
