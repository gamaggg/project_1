# RANGE — памятка для любого нового чата

Прочитай это первым. Подробности лежат в `docs/` (это хранилище Obsidian), начни с `docs/00 Главная.md`.

## Что это
RANGE — рыболовная игра-карта (catchrange.com, бот @catchrangebot, Telegram Mini App + сайт + установка на главный экран). Улов захватывает сектор воды, сектора держат кланами, за всё монеты. Города: Батуми, Москва, Санкт-Петербург, Сочи, Тбилиси.
Код: `web/` (Next.js, не тот, что в твоей памяти: перед правкой читай `web/AGENTS.md` и `node_modules/next/dist/docs/`). База: Supabase `yhgdcdkfkerzuhnzjzrz`. Хостинг: Vercel, автодеплой из `main`. Версия на сайте: `https://catchrange.com/api/version` (хеш коммита).

## Правила владельца (нарушать нельзя)
1. **Отвечай по-русски.** Приложение показывает слово «сектор», а не «территория».
2. **Не делай `git commit` и `git push`, пока владелец не написал «Комит и пуш» (или «применяй комит и пуш»).** Сначала правка, проверка, отчёт, потом ждём команду. После пуша проверь `/api/version`, что выложился именно этот коммит.
3. **Миграции в живую базу только после «применяй».** Сначала черновик + файл отката в `web/supabase-drafts/<папка>/`, прогон в откатываемой транзакции (`DO … raise exception`), показать результат. Правила: `docs/50 Эксплуатация/Миграции базы — правила.md` (не терять `DEFAULT` у RPC при `DROP`+`CREATE`, явные `GRANT` у новых таблиц и представлений).
4. **Любое изменение = запись в `docs/70 Журнал/Журнал изменений.md` + обновление заметки в `docs/` + FAQ** (`web/lib/data/faq.ts`, `faq.en.ts`, `faq.ka.ts`, общие строки `faq.rows.ts`), если меняются правила, цены, награды, числа. Числа берём из кода и базы, не из головы.
5. **Секреты, пароли, ключи сам не вводить никуда.** Владелец вводит их сам.
6. **Не усложнять и не расширять задачу.** Делай, что просили. Нашёл рядом другое: сообщи, не чини молча.

## Как проверять перед тем, как сказать «готово»
- Типы: `cd web && PATH="/Users/mag/Workspace/Project 1/.tools/node/bin:$PATH" npx tsc --noEmit` (в обычном PATH Node нет).
- Интерфейс: запусти dev-сервер через `preview_start` и проверь в браузере приложения. Telegram-режим в браузере не воспроизвести (отступы под кнопками, камера, геолокация): честно скажи, что проверить это может только владелец на телефоне.
- Прогон миграций и «что увидят живые игроки»: перед применением.

## Подводные камни, которые уже стоили времени
- `execute_sql` в Supabase возвращает только результат последнего запроса.
- Тексты на трёх языках: `web/lib/i18n/{ru,en,ka}.ts`; грузинские на проверку носителем.
- Telegram Mini App: верхние отступы берутся из `--tg-safe-area-top` (`AuthProvider.applyTelegramChrome`); iPhone и Android ведут себя по-разному, правка под одну платформу не должна ломать другую.
- Тревоги в Telegram идут из `system_health_tick` → `_system_alert`; новая категория в `client_errors` даёт тревогу.
- Vercel-коннектор (MCP) не работает (403): деплой смотри по `/api/version`, повторный деплой через пустой коммит только по команде.
- Лимиты бесплатных тарифов: команда `/limits`, заметка `docs/50 Эксплуатация/Лимиты сервисов.md`.
- **Сектора и города.** Форма секторов лежит в файлах `web/public/data/sectors-<буква>.<версия>.json`, у базы клиент просит только «непустые» строки (`docs/40 Функции/Загрузка секторов карты.md`). Всякий раз, когда ты создаёшь или удаляешь сектора пачкой (новый город, расширение сетки, чистка, миграция в `territories`), в конце задачи запусти `cd web && node scripts/build-sector-geometry.mjs` (с `.tools/node/bin` в PATH), проверь `node --no-warnings --import ./scripts/test-register.mjs scripts/verify-sector-load.mjs` и включи новые файлы и `lib/data/sectorGeometryVersion.ts` в коммит. Единичные сектора, добавленные владельцем руками в приложении, работают без пересборки (приходят строками из базы).

## Как работать быстро и без ошибок
- Сначала прочитай нужную заметку и файл, потом правь. Не угадывай, как это сделано: ищи по коду.
- Если задача неясна в одном месте, спроси одним коротким вопросом, а не придумывай.
- В конце: что сделано, что проверено, что нет (и почему), что нужно от владельца.
