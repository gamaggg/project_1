# Документация переехала в `docs/`

Документация проекта — хранилище Obsidian в папке [`docs/`](docs/). Открыть: Obsidian → «Open folder as vault» → папка `docs`. Начало — [`docs/00 Главная.md`](<docs/00 Главная.md>).

Бывшие разделы этого файла теперь отдельные заметки с теми же названиями: `docs/20 Архитектура`, `docs/30 Механики`, `docs/40 Функции`, `docs/45 Администрирование`, `docs/50 Эксплуатация`; прототип — `docs/80 Архив`. Ссылки в коде «см. DOCS.md, «…»» ведут в одноимённую заметку.
