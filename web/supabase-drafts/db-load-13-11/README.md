в очередь и не задержит за собой игроков. Тогда просто повторить через минуту.

Порядок: 01 → 01b → 02 → 03 → 05 → 06; 04 — после «Комит и пуш» и проверки `/api/version`.

(только после «да» владельца: удаляет файлы, копии сохраняет в `web/scripts/.cache/orphan-backup/`).
