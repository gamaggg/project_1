# reels-lab: ролики «Сектор захвачен» из видео владельца

Берёт вертикальное видео (рыбалка), убирает исходный звук, накладывает оболочку RANGE (логотип сверху, внизу «карта»
с секторами из приложения, настоящая анимация захвата, пилюля с рыбой и весом, заставка «Лови рыбу, захватывай сектора.»)
и собирает MP4 1080×1920 для Reels, TikTok и Shorts. Описание: `docs/10 Продукт/Монтаж роликов (Reels).md`.

Нужно: `ffmpeg` (`brew install ffmpeg`), Node (`npx hyperframes`, скачивается при первом запуске).

```bash
python3 tools/reels-lab/make_reel.py --video ~/Видео/fish.mov --species "Окунь" --weight "0,6 кг" --at 2.2 --name reel-perch
```

Параметры: `--kind captured|newfish` (захват сектора или новая рыба в коллекции), `--at` секунда появления оболочки,
`--sector B0837` номер сектора, `--color #2FA84F` цвет «моих», `--max 55` сколько секунд видео взять,
`--music файл.mp3` подложить бесплатную музыку, `--keep-audio` оставить исходный звук.
Результат: `tools/reels-lab/out/<имя>/reel.mp4` (папки `jobs/` и `out/` не в git).
